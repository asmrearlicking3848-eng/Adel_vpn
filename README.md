# Adel VPN — starter project

این پروژه یک نمونه اولیه اندروید برای نمایش فهرست رله‌های عمومی VPN Gate است.

**مهم:** این نسخه هنوز موتور OpenVPN، سرویس `VpnService`، تأیید مجوز VPN، اتصال واقعی، قطع اضطراری و بررسی سلامت تونل را ندارد. دکمه برنامه فقط فهرست رله‌ها را دریافت می‌کند؛ آن را VPN عملیاتی تلقی نکنید.

سرورهای VPN Gate داوطلبانه هستند و ممکن است قابل اعتماد یا پایدار نباشند. برای اطلاعات حساس، بانکداری یا ورود به حساب‌های مهم از آن‌ها استفاده نکنید.

## ساخت APK
GitHub Actions در هر push به شاخه `main` یک APK آزمایشی debug می‌سازد. فایل در بخش Actions و سپس Artifacts قابل دریافت است.
